El buscador no usa la API de Spotify: busca por nombre en iTunes/Apple Music y te deja escuchar un preview de 30s. Si no aparece ahí, usá el link "Buscar directo en Spotify" de arriba. Para jugar la canción, copiá su link real desde Spotify (⋯ o clic derecho → Compartir → Copiar enlace de la canción) y pegalo abajo — o simplemente volvé a esta pestaña después de copiarlo: si el portapapeles tiene un link de Spotify, se agrega solo. También puedes soltar un archivo .txt con varios links. No hace falta iniciar sesión ni tener Premium: usamos el oEmbed público de Spotify solo para el título y la portada de cada canción agregada. Tu lista queda guardada en este navegador, así que la próxima vez que entres ya la vas a tener lista — no hace falta rearmarla ("Vaciar lista" la borra).
